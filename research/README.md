# Research Directory

This directory contains research-related materials, experiments, and analysis.

## Structure

- `experiments/` - Experiment results and configurations
- `notebooks/` - Jupyter notebooks for analysis
- `papers/` - Research papers, drafts, and documentation
- `datasets/` - Research datasets (gitignored, not tracked)

## Usage

This directory is for research and experimentation. Code here may be experimental and subject to change.

For production-ready code, see the `sted/` library.
